# TaskFlow

مدير مهام بسيط مع مستويات أولوية (عالية/متوسطة/منخفضة) ووضع داكن ولون زمردي.

</div>

## الميزات
- إضافة مهام مع أولوية (عالية/متوسطة/منخفضة)
- وضع علامة مكتمل
- حذف المهام
- تصفية حسب الأولوية
- الوضع الداكن مع لون زمردي
- حفظ تلقائي في المتصفح (LocalStorage)

## البدء السريع
```bash
git clone https://github.com/mayakilzy/taskflow-app.git
cd taskflow-app
npm install
npm run dev
```
