# TaskFlow

A minimal task manager with priority levels (high/medium/low), dark mode with emerald accent, and localStorage persistence.

![Next.js](https://img.shields.io/badge/Next.js-16-black?logo=next.js) ![TypeScript](https://img.shields.io/badge/TypeScript-5-blue?logo=typescript) ![Tailwind](https://img.shields.io/badge/Tailwind-3-38BDF8?logo=tailwindcss)

## Features
- Add tasks with priority (high/medium/low)
- Mark tasks as done
- Delete tasks
- Filter by priority
- Dark mode with emerald accent
- LocalStorage persistence

## Quick Start
```bash
git clone https://github.com/mayakilzy/taskflow-app.git
cd taskflow-app
npm install
npm run dev
```
